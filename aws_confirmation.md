## AWS Confirmation

One of the project deliverables was to upload the transformed dataset into the AWS Redshift data warehouse. 
To confirm successful ingestion and accessibility, I connected the Redshift warehouse to AWS QuickSight and published a sample visualization.
This is to verify that the data is available and displaying correctly.

While Tableau was used as the primary visualization tool, the QuickSight dashboard below serves as confirmation that the data is properly stored in AWS.
